# Project 6: Biomedical Knowledge Graph Pipeline

Build a biomedical knowledge graph from PubMed abstracts. Extract genes, diseases, drugs, proteins, pathways, and cell types from medical literature, then discover drug-disease associations through multi-hop graph reasoning.

## Overview

This project demonstrates domain-specific knowledge graph construction for the biomedical domain:

1. **Fetch** PubMed abstracts using BioPython's Entrez API (with sample data fallback)
2. **Extract** biomedical entities (genes, diseases, drugs, proteins) using LLM-based NER
3. **Extract** typed relationships (TREATS, CAUSES, INHIBITS, TARGETS, etc.) with ontology constraints
4. **Build** a Neo4j knowledge graph with proper biomedical labels and indexes
5. **Query** the graph for drug-disease paths, gene-disease associations, pathway analysis
6. **Discover** drug repurposing candidates via multi-hop reasoning

## Requirements

- Python 3.11+
- Neo4j (via Docker): `docker run -d -p 7687:7687 -p 7474:7474 -e NEO4J_AUTH=neo4j/password neo4j:5`
- BioPython (for PubMed fetching)
- Shared LLM layer (LangChain-based)

## Biomedical Ontology

### Entity Types
| Type | Description |
|------|-------------|
| Gene | Human or model organism genes (e.g., TP53, BRCA1) |
| Protein | Protein products (e.g., p53, HER2) |
| Disease | Diseases and conditions (e.g., breast cancer, diabetes) |
| Drug | Pharmaceutical compounds (e.g., metformin, trastuzumab) |
| Pathway | Biological pathways (e.g., MAPK signaling, apoptosis) |
| CellType | Cell types (e.g., T-cell, hepatocyte) |
| Organism | Model organisms (e.g., Homo sapiens, Mus musculus) |

### Relationship Types
| Relationship | Source | Target |
|-------------|--------|--------|
| TREATS | Drug | Disease |
| CAUSES | Gene/Drug | Disease |
| INHIBITS | Drug | Gene/Protein |
| ACTIVATES | Drug/Gene | Gene/Protein/Pathway |
| ASSOCIATED_WITH | Gene/Protein | Disease |
| EXPRESSED_IN | Gene/Protein | CellType |
| TARGETS | Drug | Protein |
| INTERACTS_WITH | Protein | Protein |

## Pipeline

```bash
# 1. Fetch PubMed abstracts (or use sample data)
python src/01_fetch_pubmed.py --query "cancer drug target" --max_results 50

# 2. Extract biomedical entities
python src/02_extract_biomedical_entities.py

# 3. Extract relationships
python src/03_extract_relations.py

# 4. Build Neo4j graph
python src/04_build_biomedical_kg.py

# 5. Run domain-specific queries
python src/05_query_biomedical_kg.py

# 6. Drug repurposing analysis
python src/06_drug_repurposing.py
```
